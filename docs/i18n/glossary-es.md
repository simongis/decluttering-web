# Spanish glossary (EN → ES)

Use these terms in `src/i18n/es/`. If you change one, update this file in the same pull request. See `CONTRIBUTING.md` ("Translating the app").

- **Register:** informal *tú*, in neutral international Spanish. Avoid Spain-only usage: write *agregar* not *añadir*, *configuración* not *ajustes*, and *Presiona Enter* not *Pulsa Intro*.
- **Tone:** kind, plain and respectful, the same as the English. *Ordenar* (tidy up), never *limpiar* or *limpieza*.
- **Confirmed:** marks a term checked against Esri's Spanish ArcGIS Online documentation (sources at the end).
